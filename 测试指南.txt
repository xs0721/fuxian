【方法1】使用nvidia-smi

打开新终端，持续监控：
```bash
watch -n 1 nvidia-smi
```

或Windows上：
```bash
# PowerShell
while($true) { nvidia-smi; sleep 1; cls }
```

观察：
• GPU使用率
• 显存占用
• 温度

【方法2】Python脚本监控

创建 monitor.py：
```python
import torch
import time

print("开始监控显存...")
try:
    while True:
        used = torch.cuda.memory_allocated(0) / 1024**3
        reserved = torch.cuda.memory_reserved(0) / 1024**3
        total = torch.cuda.get_device_properties(0).total_memory / 1024**3
        print(f"[{time.strftime('%H:%M:%S')}] 使用: {used:.2f}GB | 保留: {reserved:.2f}GB | 总: {total:.1f}GB", end='\r')
        time.sleep(1)
except KeyboardInterrupt:
    print("\n监控结束")
```

运行：
```bash
python monitor.py
```
