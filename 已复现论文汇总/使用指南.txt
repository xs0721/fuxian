【示例1：使用Logits层水印（KGW, STA-1, SIR等）】

```python
from run_experiment import STA1LogitsProcessor, detect_watermark
from transformers import AutoModelForCausalLM, AutoTokenizer, LogitsProcessorList
import torch

# 加载模型
model = AutoModelForCausalLM.from_pretrained("facebook/opt-125m")
tokenizer = AutoTokenizer.from_pretrained("facebook/opt-125m")
vocab_size = 50272
device = "cuda"

# 生成水印文本
prompt = "Machine learning is"
input_ids = tokenizer.encode(prompt, return_tensors="pt").to(device)

processor = STA1LogitsProcessor(vocab_size, gamma=0.5, delta=2.0)
outputs = model.generate(
    input_ids,
    max_new_tokens=50,
    logits_processor=LogitsProcessorList([processor]),
    do_sample=True,
    temperature=0.7
)

watermarked_text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print("带水印文本:", watermarked_text)

# 检测水印
z_score = detect_watermark(watermarked_text, "KGW", tokenizer, vocab_size)
print(f"Z-score: {z_score:.2f}")
```

【示例2：使用Prompt层水印（ICW）】


【示例3：对比不同算法】

```python
from run_experiment import (
    KGWLogitsProcessor,
    STA1LogitsProcessor,
    SIRLogitsProcessor,
    XSIRLogitsProcessor,
    detect_watermark
)

algorithms = {
    'KGW': KGWLogitsProcessor(vocab_size),
    'STA-1': STA1LogitsProcessor(vocab_size),
    'SIR': SIRLogitsProcessor(vocab_size),
    'X-SIR': XSIRLogitsProcessor(vocab_size)
}

for name, processor in algorithms.items():
    # 生成
    outputs = model.generate(
        input_ids,
        max_new_tokens=50,
        logits_processor=LogitsProcessorList([processor])
    )
    text = tokenizer.decode(outputs[0], skip_special_tokens=True)

    # 检测
    z_score = detect_watermark(text, name, tokenizer, vocab_size)
    print(f"{name:10} | Z-score: {z_score:6.2f}")
```

【示例4：使用EWD熵加权检测】

```python
from run_experiment import detect_watermark

# 标准KGW检测
z_kgw = detect_watermark(text, "KGW", tokenizer, vocab_size)

# EWD熵加权检测（更低误报率）
z_ewd = detect_watermark(text, "EWD", tokenizer, vocab_size)

print(f"KGW Z-score: {z_kgw:.2f}")
print(f"EWD Z-score: {z_ewd:.2f}")
print(f"EWD改进: {z_ewd - z_kgw:+.2f}")
```

Q1: 为什么有些算法没实现？
A: AWT、REMARK、RL-Watermark需要端到端训练（数天-数周），
   不适合快速复现。已有详细分析文档说明原因。

Q2: ICW效果为什么不明显？
A: ICW依赖模型对指令的遵循能力，OPT-125m太小。
   论文使用GPT-4等大模型效果更好。

Q3: 如何评估水印质量？
A: 运行test文件会生成图表，包含：
   • 检测率（Z-score）
   • 文本质量（PPL）
   • 鲁棒性（改写后检测率）
