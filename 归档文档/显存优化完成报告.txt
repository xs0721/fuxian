【测试1】显存监控脚本

创建 `monitor_memory.py`:
```python
import torch
import time
import subprocess
import sys

print("开始监控显存...")
print(f"总显存: {torch.cuda.get_device_properties(0).total_memory / 1024**3:.1f} GB")

# 运行run_experiment.py
process = subprocess.Popen([sys.executable, "run_experiment.py"],
                          stdout=subprocess.PIPE,
                          stderr=subprocess.PIPE)

while process.poll() is None:
    allocated = torch.cuda.memory_allocated(0) / 1024**3
    reserved = torch.cuda.memory_reserved(0) / 1024**3
    print(f"已用: {allocated:.2f}GB | 保留: {reserved:.2f}GB", end='\r')
    time.sleep(1)

print("\n运行完成！")
```

运行：
