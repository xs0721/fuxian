一、复现方案选择
================================================================================

采用方案: 方案B - 简化版复现（推荐方案）✅

理由:
1. ✅ 无需多语言模型（XLM-R, mBERT等）
2. ✅ 可在现有单语言环境运行
3. ✅ 体现核心思想：语义鲁棒性
4. ✅ 用改写测试代替翻译测试
5. ✅ 实现难度适中

核心策略:
- 使用鲁棒语义哈希代替多语言编码器
- token集合（set）而非序列，忽略顺序
- DIPPER改写模拟跨语言场景

```python
class XSIRLogitsProcessor(LogitsProcessor):
    """X-SIR: Cross-lingual Semantic Invariant Robust Watermark

    简化版：用鲁棒语义哈希代替XLM-R多语言编码器
    """
    def __init__(self, vocab_size, gamma=0.5, delta=2.0,
                 hash_key=15485863, aggregation='set'):
        self.aggregation = aggregation  # 'set', 'bag', 'sum'

    def _semantic_hash_robust(self, context_ids):
        """对token顺序和小变化不敏感的哈希"""
        context = context_ids[-8:]

        if self.aggregation == 'set':
            # 集合哈希（最鲁棒）
            token_set = sorted(set(context))
            h = sum(token_set) % (2**31 - 1)
        # ...其他方法

        return h ^ self.hash_key
```

特点:
✅ 对token顺序不敏感
✅ 语义相似 → 哈希相似 → 绿名单重叠
✅ 改写/翻译后仍可检测

五、使用示例

【生成X-SIR水印】
```python
from run_experiment import XSIRLogitsProcessor
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("facebook/opt-125m")
tokenizer = AutoTokenizer.from_pretrained("facebook/opt-125m")

# X-SIR水印生成
processor = XSIRLogitsProcessor(vocab_size=50272, gamma=0.5, delta=2.0)
outputs = model.generate(
    input_ids,
    max_new_tokens=50,
    logits_processor=LogitsProcessorList([processor])
)
```

【检测X-SIR水印】
```python
from run_experiment import detect_watermark

# 检测原文
z_score_original = detect_watermark(text_original, "X-SIR", tokenizer, 50272)

# 检测改写/翻译文本
z_score_translated = detect_watermark(text_translated, "X-SIR", tokenizer, 50272)

# 评估一致性
consistency = 1 - abs(z_score_original - z_score_translated) / max(z_score_original, 1)
print(f"跨语言一致性: {consistency:.2%}")
```

【对比KGW vs X-SIR】
```python
# KGW水印
```

================================================================================
七、核心优势
================================================================================

X-SIR相比标准水印的优势:

1. **跨语言鲁棒性** 🌍
   - 英→中翻译后仍可检测
   - 多语言场景适用

2. **改写鲁棒性** 💪
   - 对深度改写（DIPPER）更鲁棒
   - 对token顺序变化不敏感

3. **语义保持** 📝
   - 基于语义而非token ID
   - 语义相似 → 检测一致

4. **实用性** 🎯
   - 全球化内容保护
   - 多语言抄袭检测

================================================================================
八、局限性说明
================================================================================

简化版的局限:

1. **不是真正的跨语言**
   - 没有使用多语言编码器
   - 用改写模拟翻译

2. **精度略低**
   - 启发式哈希 vs 深度语义编码
   - 可能不如完整版准确

3. **语言覆盖**
   - 仅在单语言环境测试
   - 未测试真实翻译场景

4. **性能差距**
   - 简化版可能达不到论文报告的70-80%
   - 但核心思想得到验证

升级到完整版需要:
- 安装XLM-R: `transformers.AutoModel.from_pretrained("xlm-roberta-base")`
- 翻译模型: MarianMT, NLLB
- 多语言测试集

十、与其他算法的关系
================================================================================

X-SIR是SIR的扩展:

SIR (27_SIR):
- 语义不变水印
- 单语言场景
- 对改写鲁棒

X-SIR (28_CWRA-X-SIR):
- SIR + 跨语言
- 多语言场景
- 对翻译鲁棒

两者关系:
- X-SIR = SIR + 多语言编码器
- 简化版X-SIR ≈ 更鲁棒的SIR

算法家族:
KGW → SIR → X-SIR
   ↓
   改写鲁棒性逐步提升
