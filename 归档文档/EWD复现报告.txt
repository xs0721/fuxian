一、EWD核心思想
================================================================================

EWD不是生成新水印的方法，而是**改进KGW检测**的方法

问题：
    标准KGW检测对所有token位置给予相同权重，导致：
    - 误报率高（FPR高）
    - 对人类文本不够友好
    - 低熵位置（模型确定的词）也被同等计算

解决方案：
    使用**熵加权**：
    - 高熵位置（模型不确定）→ 权重高 (w_i大)
    - 低熵位置（模型确定）→ 权重低 (w_i小)

数学公式：
    标准KGW: Z = (G - n*γ) / sqrt(n*γ(1-γ))
    EWD:     Z = (Σw_i*g_i - Σw_i*γ) / sqrt(Σw_i*γ(1-γ))

    其中:
    - w_i = f(H(x_i | x_1...x_{i-1})) 是位置i的熵权重
    - H是条件熵
    - g_i ∈ {0,1} 表示token是否在绿名单

### 2.1 辅助函数（完整版，需要模型）

```python
def calculate_entropy_for_ewd(model, tokenizer, tokens, device):
    """计算每个token位置的真实条件熵"""
    entropy_list = []
    with torch.no_grad():
        for i in range(1, len(tokens)):
            prefix = tokens[:i].unsqueeze(0).to(device)
            outputs = model(prefix)
            logits = outputs.logits[0, -1, :]
            probs = F.softmax(logits, dim=-1)
            entropy = -torch.sum(probs * torch.log(probs + 1e-10)).item()
            entropy_list.append(entropy)
    return entropy_list
```

### 2.2 检测函数（简化版，无需模型）

在 detect_watermark() 中添加了 "EWD" 分支：

```python
elif algo_name == "EWD":
    entropy_weights = []
    for i in range(1, len(tokens)):
        if i > 1:
            # 启发式熵估计：token差异 ≈ 不确定性
            token_diff = abs(tokens[i].item() - tokens[i-1].item())
            weight = 0.7 + 0.6 * min(token_diff / vocab_size, 1.0)
        else:
            weight = 1.0
        entropy_weights.append(weight)

        # KGW检测 + 熵权重
        torch.manual_seed(secret_key * tokens[i - 1].item())
        if (torch.rand(vocab_size) < gamma)[tokens[i].item()]:
            green_tokens_count += weight  # 使用权重而不是1

    # 加权统计量
    weighted_total = sum(entropy_weights)
    expected_green = weighted_total * gamma
    weighted_variance = sum(w * gamma * (1 - gamma) for w in entropy_weights)
    z_score = (green_tokens_count - expected_green) / math.sqrt(weighted_variance)
    return z_score
```

### 2.3 两种实现方式

**方式1：完整版（准确但慢）**
- 需要加载模型
- 对每个位置前向传播计算真实熵
- 适合离线评估和研究

**方式2：简化版（快速但近似）**
- 无需模型
- 使用启发式规则估计熵（token差异）
- 适合实时检测和大规模应用
- 当前默认使用此版本

七、与其他算法的关系
================================================================================

EWD是**检测方法**，不是**生成方法**：

生成算法（水印嵌入）:
  - KGW, SWEET, DiPmark, Unigram, SemStamp...
  - 在生成时修改logits

检测算法（水印检测）:
  - 标准Z-score检测（KGW原始）
  - EWD熵加权检测（改进版）
  - 可以应用于任何基于绿名单的水印

因此：EWD可以与任何KGW系列水印配合使用

八、扩展方向
================================================================================

当前实现使用简化的启发式熵估计，可以进一步改进：

1. 完整熵计算
   - 加载模型进行前向传播

   - 更准确但更慢

2. 缓存优化
   - 预计算常见前缀的熵
   - 使用查找表加速

3. 自适应权重
   - 根据文本类型调整权重函数
   - 学习最优权重映射

4. 扩展到其他水印
   - 应用EWD到Unigram, SWEET等
   - 统一的熵加权框架
