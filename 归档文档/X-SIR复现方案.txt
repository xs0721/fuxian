一、X-SIR核心思想
================================================================================

X-SIR是SIR（Semantic Invariant Robust）的跨语言扩展版本

问题背景:
    - 标准水印（如KGW）在翻译后完全失效
    - Token序列改变 → 绿名单不同 → 检测失败
    - 需要跨语言一致的水印方案

X-SIR解决方案:
    1. 使用跨语言语义编码器（如XLM-R, mBERT）
    2. 提取语言无关的语义表示
    3. 基于语义表示生成绿名单（而非token ID）
    4. 翻译后语义相似 → 绿名单相似 → 水印保持

关键创新:
    - CWRA (Cross-lingual Watermark Robustness Analysis) 评估框架
    - X-SIR算法：跨语言语义不变水印
    - 在中英、英中、多语言翻译场景下保持水印

================================================================================
二、为什么复现困难？
================================================================================

需要的额外资源:
❌ 1. 多语言模型（XLM-R, mBERT, mT5等）
    - 需要额外下载多个大模型
    - 内存和计算开销大

❌ 2. 翻译模型（MarianMT, NLLB等）
    - 用于测试跨语言一致性
    - 需要多个翻译方向的模型

❌ 3. 多语言测试数据
    - 中英对照数据集
    - 多语言并行语料

❌ 4. 语义编码器集成
    - 需要在生成时调用语义编码器
    - 增加推理时间和复杂度

当前环境限制:
    - run_experiment.py 基于单语言模型（OPT-125m）
    - 没有配置多语言模型
    - 测试数据为英文

```python
from transformers import AutoModel, AutoTokenizer

# XLM-R编码器
xlmr_model = AutoModel.from_pretrained("xlm-roberta-base")
xlmr_tokenizer = AutoTokenizer.from_pretrained("xlm-roberta-base")

class XSIRLogitsProcessor(LogitsProcessor):
    def __init__(self, vocab_size, semantic_model, gamma=0.5, delta=2.0):
        self.vocab_size = vocab_size
        self.semantic_model = semantic_model  # XLM-R或mBERT
        self.gamma = gamma
        self.delta = delta

    def _get_semantic_embedding(self, context_ids):
        """提取跨语言语义嵌入"""
        with torch.no_grad():
            outputs = self.semantic_model(context_ids)
            # 使用[CLS] token或池化表示
            semantic_vec = outputs.last_hidden_state[:, 0, :]  # [CLS]
        return semantic_vec

    def __call__(self, input_ids, scores):
        for b in range(input_ids.shape[0]):
            # 获取语义嵌入
            semantic_vec = self._get_semantic_embedding(input_ids[b])

            # 基于语义向量生成绿名单（而非token ID）
            semantic_hash = int(semantic_vec.sum().item() * 1e6) % (2**31)
            g = torch.Generator(device='cpu')
            g.manual_seed(semantic_hash)

            greenlist_size = int(self.vocab_size * self.gamma)
            perm = torch.randperm(self.vocab_size, generator=g)
            scores[b, perm[:greenlist_size].to(scores.device)] += self.delta

        return scores
```

方案B: 简化版复现（推荐）
────────────────────────────────────────────────────────

核心思想: 在单语言环境中模拟跨语言语义一致性

实现策略:
1. 不使用真实的多语言模型
2. 用"伪语义哈希"模拟语义不变性
3. 测试改写而非翻译（改写类似翻译的语义保持）

```python
class XSIRSimplifiedLogitsProcessor(LogitsProcessor):
    """X-SIR简化版：用上下文聚合模拟跨语言语义"""
    def __init__(self, vocab_size, gamma=0.5, delta=2.0, hash_key=15485863):
        self.vocab_size = vocab_size
        self.gamma = gamma
        self.delta = delta
        self.hash_key = hash_key

    def _semantic_hash_robust(self, context_ids):
        """鲁棒语义哈希：对token顺序和小变化不敏感"""
        # 方法1: 使用token的集合而非序列
        token_set = sorted(set(context_ids[-8:]))  # 去重+排序
        h = 0
        for token_id in token_set:
            h = (h + int(token_id)) % (2**31 - 1)
        return h ^ self.hash_key

    def __call__(self, input_ids, scores):
        for b in range(input_ids.shape[0]):
            # 鲁棒语义哈希
            semantic_seed = self._semantic_hash_robust(input_ids[b].tolist())
            g = torch.Generator(device='cpu')
            g.manual_seed(semantic_seed)

            greenlist_size = int(self.vocab_size * self.gamma)
            perm = torch.randperm(self.vocab_size, generator=g)
            scores[b, perm[:greenlist_size].to(scores.device)] += self.delta

        return scores
```

```python
class XSIRLogitsProcessor(LogitsProcessor):
    """X-SIR: Cross-lingual Semantic Invariant Robust Watermark (ACL 2024)

    简化版实现：用鲁棒语义哈希模拟跨语言一致性
    完整版需要XLM-R等多语言编码器
    """
    def __init__(self, vocab_size, gamma=0.5, delta=2.0, hash_key=15485863,
                 aggregation='set'):
        self.vocab_size = vocab_size
        self.gamma = gamma
        self.delta = delta
        self.hash_key = hash_key
        self.aggregation = aggregation  # 'set' or 'bag'

    def _semantic_hash_robust(self, context_ids):
        """鲁棒语义哈希：对token顺序和小变化不敏感

        策略：
        - 使用集合（set）而非序列，忽略顺序
        - 或使用词袋（bag），计数但不考虑位置
        """
        context = context_ids[-8:]  # 取最后8个token作为上下文

        if self.aggregation == 'set':
            # 方法1: 集合哈希（最鲁棒）
            token_set = sorted(set(context))
            h = sum(token_set) % (2**31 - 1)
        elif self.aggregation == 'bag':
            # 方法2: 词袋哈希（考虑频率）
            from collections import Counter
            token_bag = Counter(context)
            h = sum(token_id * count for token_id, count in token_bag.items())
            h = h % (2**31 - 1)
        else:
            # 方法3: 加权求和（权重相同）
            h = sum(context) % (2**31 - 1)

        return h ^ self.hash_key

    def __call__(self, input_ids, scores):
        for b in range(input_ids.shape[0]):
            # 计算鲁棒语义哈希
            semantic_seed = self._semantic_hash_robust(input_ids[b].tolist())

            # 基于语义生成绿名单
            g = torch.Generator(device='cpu')
            g.manual_seed(semantic_seed)
            greenlist_size = int(self.vocab_size * self.gamma)
            perm = torch.randperm(self.vocab_size, generator=g)

            scores[b, perm[:greenlist_size].to(scores.device)] += self.delta

        return scores
```

```python
elif algo_name == "X-SIR":
    """X-SIR检测：使用鲁棒语义哈希"""
    green_tokens_count = 0

    for i in range(1, len(tokens)):
        # 获取上下文
        context = tokens[max(0, i-8):i].tolist()

        # 鲁棒语义哈希（与生成时一致）
        token_set = sorted(set(context))
        semantic_hash = sum(token_set) % (2**31 - 1)
        semantic_seed = semantic_hash ^ secret_key

        # 检测绿名单
        g = torch.Generator(device='cpu')
        g.manual_seed(semantic_seed)
        greenlist_size = int(vocab_size * gamma)
        perm = torch.randperm(vocab_size, generator=g)
        greenlist = set(perm[:greenlist_size].tolist())

        if tokens[i].item() in greenlist:
            green_tokens_count += 1

    variance = total_tokens * gamma * (1 - gamma)
    if variance == 0: return 0.0
    z_score = (green_tokens_count - total_tokens * gamma) / math.sqrt(variance)
    return z_score
```
