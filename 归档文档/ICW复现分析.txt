一、ICW核心思想
================================================================================

【问题定位】

传统水印的局限:
❌ 需要访问模型解码过程（logits）
❌ 无法应用于黑盒API（如GPT-4）
❌ 不适合检测别人使用你的模型生成的文本

ICW的创新:
✅ 通过提示词（prompt）嵌入水印
✅ 完全黑盒，无需访问模型内部
✅ 适用于任何LLM（包括闭源API）

【核心机制】

ICW = In-Context Learning + Watermark Instructions

原理:
1. 在系统提示词中嵌入水印指令
2. 指令要求模型偏向某些特征（首字母、词汇等）
3. 通过统计检测这些特征来识别水印

例子（Initials水印）:
```
System Prompt:
"请优先使用以 a, e, i, o, t 开头的单词（绿名单）
 减少使用以 b, c, d, f, g 开头的单词（红名单）"

User: "Explain machine learning"
Model: "Artificial intelligence enables..." ← 偏向绿名单首字母
```

- 通过提示词引导（应用层面）

```python
class ICWInitialsWatermark:
    """ICW Initials水印：通过提示词偏向特定首字母"""

    def __init__(self, green_letters=['a','e','i','o','t','s','r','h'],
                       red_letters=['b','c','d','f','g','j','k','l']):
        self.green_letters = [l.lower() for l in green_letters]
        self.red_letters = [l.lower() for l in red_letters]
        self.gamma = len(green_letters) / (len(green_letters) + len(red_letters))

    def generate_system_prompt(self):
        """生成包含水印指令的系统提示词"""
        return f"""
You are a helpful assistant.

IMPORTANT INSTRUCTION (Secret):
When responding, try to use more words that start with these letters:
{', '.join(self.green_letters)}

And use fewer words that start with these letters:
{', '.join(self.red_letters)}

Still maintain natural and helpful responses.
"""

    def generate_with_watermark(self, model, tokenizer, prompt):
        """使用ICW生成带水印文本"""
        # 构造完整prompt
        full_prompt = self.generate_system_prompt() + f"\n\nUser: {prompt}\n\nAssistant:"

        # 标准生成（无LogitsProcessor）
        input_ids = tokenizer.encode(full_prompt, return_tensors="pt").to(device)
        outputs = model.generate(
            input_ids,
            max_new_tokens=100,
            do_sample=True,
            temperature=0.7
        )

        response = tokenizer.decode(outputs[0][len(input_ids[0]):], skip_special_tokens=True)
        return response

    def detect_watermark(self, text, tokenizer):
        """检测ICW水印"""
        # 分词
        words = text.lower().split()

        # 统计首字母
        green_count = 0
        total_count = 0

        for word in words:
            if len(word) > 0 and word[0].isalpha():
                first_letter = word[0]
                if first_letter in self.green_letters or first_letter in self.red_letters:
                    total_count += 1
                    if first_letter in self.green_letters:
                        green_count += 1

        if total_count == 0:
            return 0.0

        # 计算Z-score
        expected = total_count * self.gamma
        variance = total_count * self.gamma * (1 - self.gamma)
        z_score = (green_count - expected) / (variance ** 0.5 + 1e-10)

        return z_score
```

【使用方法】

```python
# 生成
icw = ICWInitialsWatermark()
watermarked_text = icw.generate_with_watermark(model, tokenizer, "Explain AI")

# 检测
z_score = icw.detect_watermark(watermarked_text, tokenizer)
print(f"Z-score: {z_score:.2f}")
```

```python
class ICWAcrosticsWatermark:
    """ICW Acrostics: 句首字母隐藏消息"""

    def __init__(self, hidden_message="AI"):
        self.message = hidden_message.upper()

    def generate_system_prompt(self):
        return f"""
When responding, structure your answer as multiple sentences.
Make the first letter of each sentence spell out: {self.message}
(but keep the response natural and coherent)
"""

    def detect_watermark(self, text):
        """提取句首字母"""
        sentences = text.split('.')
        acrostic = ''.join([s.strip()[0].upper() for s in sentences if s.strip()])
        return self.message in acrostic


class ICWLexicalWatermark:
    """ICW Lexical: 偏向特定词汇"""

    def __init__(self, green_words=['innovative','advanced','intelligent']):
        self.green_words = set(w.lower() for w in green_words)

    def generate_system_prompt(self):
        return f"""
When possible, use these words in your response:
{', '.join(self.green_words)}
"""

    def detect_watermark(self, text):
        """统计特定词汇频率"""
        words = text.lower().split()
        count = sum(1 for w in words if w in self.green_words)
        return count / max(len(words), 1)
```

================================================================================
七、ICW的优势与局限
================================================================================

【优势】✅

1. **黑盒友好**
   - 适用于任何LLM（GPT-4, Claude等）
   - 无需访问模型内部

2. **易于部署**
   - 只需修改prompt
   - 无需训练或微调

3. **应用场景广**
   - 学术审稿防作弊
   - API服务追踪
   - 内容溯源

【局限】❌

1. **依赖模型遵循**
   - 小模型可能无法理解指令
   - OPT-125m效果可能不佳

2. **鲁棒性较弱**
   - 改写容易破坏
   - 不如logits层面的水印鲁棒

3. **隐蔽性低**
   - 系统提示词可能泄露
   - 容易被发现和移除

4. **文本质量影响**
   - 偏向特定首字母/词汇会影响自然度
   - 需要平衡水印强度和质量

- 优点: 适用任何LLM

- 优点: 理论最优
