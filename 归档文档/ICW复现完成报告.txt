二、ICW核心特点
================================================================================

【与传统水印的根本区别】

传统水印（KGW, SWEET, SIR等）:
- 修改模型logits（白盒）
- 需要访问模型内部
- 实现为LogitsProcessor

ICW（本算法）:
- 修改系统提示词（黑盒）✅
- 无需访问模型内部
- 实现为独立类

【核心机制】

```
传统水印流程:
用户prompt → 模型 → LogitsProcessor修改概率 → 带水印文本

ICW流程:
系统提示词（含水印指令）+ 用户prompt → 模型 → 带水印文本
```

关键：水印在**应用层**，不在**模型层**

五、ICW的优势与局限
================================================================================

【优势】✅

1. **完全黑盒**
   - 适用于任何LLM（GPT-4, Claude, Gemini等）
   - 无需访问模型内部
   - 适用于闭源API

2. **易于部署**
   - 只需修改系统提示词
   - 无需训练或微调
   - 即插即用

3. **应用场景广**
   - 学术审稿防作弊（论文的主要场景）
   - API服务溯源
   - 内容版权保护

4. **灵活性高**
   - 可以动态调整水印强度
   - 支持多种变体（Initials, Lexical, Acrostics等）

【局限】❌

1. **依赖模型能力**
   - 小模型（OPT-125m）可能无法理解复杂指令
   - 大模型（GPT-4）效果更好
   - 本实现在OPT-125m上为概念验证

2. **鲁棒性较弱**
   - 改写容易破坏
   - 不如logits层水印鲁棒

3. **隐蔽性低**
   - 系统提示词可能泄露
   - 容易被发现和移除

4. **文本质量影响**
   - 偏向特定首字母/词汇影响自然度
   - 需要平衡水印强度和质量

八、ICW在水印生态中的定位
================================================================================

【水印技术分类】

1. **Logits层水印**（需要白盒）
   - KGW, SWEET, SIR, X-SIR, STA-1, KTH, TBW等
   - 优点: 鲁棒、隐蔽
   - 缺点: 需要模型访问

2. **Prompt层水印**（黑盒友好）⭐ ICW属于这一类
   - ICW (唯一代表)
   - 优点: 适用任何LLM
   - 缺点: 鲁棒性较弱

3. **端到端训练**（需要重新训练）
   - AWT, REMARK-LLM
   - 优点: 理论最优
   - 缺点: 成本极高

【ICW的独特价值】

✅ 填补了黑盒场景的空白
✅ 是run_experiment.py中唯一的prompt-based水印
✅ 代表了水印技术的新方向
