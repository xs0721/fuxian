三、常见问题及解决方案
================================================================================

【问题1】运行卡在"Loading weights"

原因：第一次下载模型，网络慢
解决：
• 等待下载完成（约500MB）
• 使用镜像加速：
  ```bash
  export HF_ENDPOINT=https://hf-mirror.com
  ```

【问题2】CUDA out of memory

原因：显存不足
解决：
• 降低batch_size
• run_experiment.py中搜索batch_size，改小一点
• 或者关闭其他占用GPU的程序

但对OPT-125M来说，8GB显存不应该不够

【问题3】ImportError: No module named 'xxx'

原因：缺少依赖
解决：
```bash
pip install transformers datasets tqdm scipy scikit-learn
```

【问题4】运行很慢

原因：正常现象
• OPT-125M生成200个样本需要10-30分钟
• 这不是"跑不通"，是需要等待

优化：
• 减少TEST_SAMPLE_SIZE（run_experiment.py第15行）
• 从200改成50或20

【问题5】路径错误

原因：Windows路径问题
解决：
• 使用正斜杠 `/` 而不是反斜杠 `\`
• 或使用原始字符串 `r"E:\path"`
